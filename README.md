# Home of Creativity — Company Profile

Premium bilingual (Arabic / English) company profile for **Home of Creativity (Creativation Source)**.

## Live site

**https://home-of-creativity.github.io/home-of-creativity-profile/**

Local `npm run dev` is at **http://localhost:3000/home-of-creativity-profile/**

```bash
npm install
npm run dev
```

Production is a static export. GitHub Actions deploys the `out/` folder to Pages.

## E2E (landing)

With the dev server running:

```bash
npm run e2e
```
